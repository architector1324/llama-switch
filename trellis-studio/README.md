# Trellis Studio

Browser UI adapted from [trellis.cpp](https://github.com/pwilkin/trellis.cpp) commit `6851891d706e2e26a8bb9dd99f28de851d68b64d`, under its MIT license. It uses the model named in the URL and routes requests through llama-switch. The bundled model-viewer is BSD-3-Clause licensed.

Run `npm ci` and `npm run build`, then replace `../src/static/studio` with `dist` before building llama-switch.
